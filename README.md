# govbot-cli

A CLI-based AI helpdesk for government employees — ask questions about leave, transfers, and HR procedures in plain language.

## Features
- Multi-turn conversation with context memory
- Knowledge base covering leave rules, transfers, MACP, GPF, LTC, RTI and more
- Color-coded responses in the terminal
- Graceful fallback when query is outside knowledge base

## Tech Stack
Python · Groq API · colorama · python-dotenv
